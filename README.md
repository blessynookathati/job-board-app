## 📌 Overview

A modern **Job Board Application** built using React that allows users to search, filter, sort, and bookmark job listings.

This project demonstrates real-world frontend concepts like:
- Advanced filtering
- State management
- Local storage persistence
- Responsive UI design
- Docker containerization

---

## ✨ Features

| Feature | Description |
|--------|------------|
| 🔍 Search | Search jobs by title or company |
| 🎯 Filters | Filter by job type, skills, salary |
| 🧠 Multi-Skill Filter | Select multiple skills simultaneously |
| 🔽 Sorting | Sort jobs by salary (high → low) |
| 📄 Pagination | Navigate through job listings |
| 💾 Bookmark | Save jobs using localStorage |
| 📌 Tracker Page | View bookmarked jobs |
| 🔄 Clear Filters | Reset all filters instantly |
| 📱 Responsive UI | Works on all devices |
| 🐳 Dockerized | Run using Docker |
